An invented passport spread for the Republic of Veskar, a country that isn't there: a data page with a portrait and machine-readable zone, and a facing page with a compass emblem, entry stamps and a signature. It runs offline and writes the image to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
